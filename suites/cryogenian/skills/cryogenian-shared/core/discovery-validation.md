# Discovery And Validation

Keep two spaces distinct.

## Discovery

Generate before filtering. Use anomalies, proxy disagreement, missing mass or
flux, reversed causality, hidden variables, cross-scale discontinuities,
preservation bias, counterfactuals, and cross-domain analogies. Label outputs
`ANOM`, `IDEA`, or `HYP`; label originality `NOVELTY-UNK`. Do not reject an idea
because it lacks precedent, data, or immediate feasibility.

## Validation

For selected candidates, run targeted literature search, mechanism accounting,
alternative comparison, unique predictions, falsifiers, kill tests, feasibility,
and information-gain ranking. Report maturity rather than a binary accept/reject:
`speculative`, `mechanistically-formed`, `literature-compatible`,
`test-ready`, or `weakened`.
