# Terminology

Preserve reported isotope notation. Distinguish `delta202Hg` mass-dependent
fractionation from `Delta199Hg` and `Delta201Hg` mass-independent fractionation.
Use Greek symbols only when the output environment renders them reliably.

Treat Cryogenian iron formation as `CIF`; use `BIF` when matching source
terminology. Distinguish liquid water, weak ice cover, leads/polynyas, seasonal
open water, persistent open water, and basin-scale ice-free conditions.
Distinguish habitability, presence, activity, expansion, preservation, and
causal response.
