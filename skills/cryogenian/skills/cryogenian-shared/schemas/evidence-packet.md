# Evidence Packet Schema

1. Question, claim boundary, search date, and access mode.
2. Search concepts, inclusion/exclusion criteria, and sources queried.
3. Source table: identifier, primary/secondary type, access, relevance, freshness.
4. Claim-source matrix with locators and supporting/opposing status.
5. Conflicts, unavailable evidence, and static-guidance discrepancies.
6. Bounded synthesis and next refresh trigger.
7. Exportable DOI/BibTeX/RIS list when requested.
