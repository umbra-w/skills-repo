# Knowledge Record Schema

```yaml
claim: bounded statement
status: stable | contested | provisional | deprecated
last_reviewed: YYYY-MM-DD
valid_scope: time, place, material, proxy and preservation domain
known_conflicts: supporting and opposing source identifiers
refresh_trigger: observable condition requiring a new search
source_requirement: primary | primary-plus-review | method-standard
```

No task Skill may silently convert this record into an observation.
