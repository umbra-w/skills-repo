# Evidence Freshness

Static files provide methods, vocabulary, and failure checks. They are not case
evidence and cannot establish current consensus, novelty, chronology, locality
facts, proxy calibration, or causal mechanisms.

Use these states:

| State | Meaning |
|---|---|
| `LIVE-VERIFIED` | Checked in an accessible primary source during this task |
| `USER-SUPPLIED` | Supplied by the user and not independently verified |
| `STATIC-HEURISTIC` | Durable method guidance, never an observation |
| `CONTESTED` | Credible sources support incompatible interpretations |
| `STALE` | Review date exceeded or newer evidence may supersede it |
| `SOURCE-NEEDED` | Material source or locator is unavailable |

Refresh is mandatory for latest/current/consensus/novelty questions; named
sites, beds, or numerical values; chronology; causal claims; publication
decisions; and conflicts between task evidence and installed guidance. Prefer
primary sources and record search date, access level, and locators. New evidence
may override a static heuristic, but explain why.
