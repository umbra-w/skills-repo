# Source Foundation

This is a discovery and method-orientation list, not a substitute for reading
the primary sources. Titles, years, and DOIs below were cross-checked through
OpenAlex and Crossref on 2026-07-28. Inspect the paper, supplementary material,
and any later correction before using a source for a specific claim.

## Source Hierarchy

1. User data, field relationships, and analytical documentation for site claims.
2. Primary paper and supplement for method, sample, and result claims.
3. Authoritative method/review source for terminology and known limitations.
4. Later independent tests for contested interpretations.

A high-profile review provides context but does not replace the primary paper
for Nanhua Basin or sample-level evidence.

## Use Protocol

When a rule needs support:

1. open the most relevant primary or method paper;
2. capture the exact claim, method, samples, and limitations with a pointer;
3. check whether later work modifies the interpretation;
4. label imported statements `CTX`, never `OBS` for the user's section;
5. add a new source here only after DOI/title/year cross-verification.

If a citation cannot be verified, mark `SOURCE_NEEDED` in the work product rather
than fabricating bibliographic details.
