# Cryogenian Polishing

Improve language and argument visibility while preserving scientific content.

## Scope

Read `../cryogenian-shared/core/task-scope.md` and
`../cryogenian-shared/core/terminology.md`.

- `POINT`: return the polished sentence or phrase first. Add a note only if a
  scientific ambiguity or meaning change requires author confirmation.
- `COMPONENT`: polish the passage and summarize material scientific edits.
- `SYSTEM`: establish a style sheet, edit consistently, and audit terminology,
  cross-references, claims, and internal contradictions.

## Editing Contract

Preserve numbers, units, isotope notation, sample names, stratigraphy,
citations, uncertainty, modality, causal strength, and spatial-temporal scale.
Do not silently turn association into causation, potential into occupation,
local into global, or hypothesis into observation. Do not add facts or
citations to make prose sound authoritative.

Prefer precise verbs, concrete subjects, short logical sentences, and one
argumentative job per paragraph. Remove repetition and nominalization where it
improves clarity. Retain technical terms that carry necessary distinctions.
Match the target journal's level of compression without copying published
phrasing.

## Output

For `POINT`, output only the revision unless explanation is necessary. For
larger work return polished text, a short edit memo, unresolved scientific
ambiguities, and a terminology/style sheet. If the source meaning is unclear,
offer a marked conservative rendering rather than inventing intent.
